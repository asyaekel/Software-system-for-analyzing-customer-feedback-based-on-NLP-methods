# Програмна система для аналізу клієнтських відгуків на основі методів NLP

**(Software system for analyzing customer feedback based on NLP methods)**

Даний проєкт представляє собою SaaS-рішення для інтелектуального аналізу клієнтських відгуків. Система використовує сучасні методи обробки природної мови (NLP), зокрема бібліотеку SetFit (Few-Shot Fine-Tuning), для класифікації текстів та визначення тональності за 11 ключовими бізнес-критеріями.

## Основні можливості

- **Інтелектуальний NLP-аналіз**: Система виконує сегментацію відгуку на окремі речення та ідентифікує згадки специфічних аспектів (якість, ціна, доставка, підтримка тощо) з подальшою оцінкою за 10-бальною шкалою.
- **Інтерактивний дашборд**: Реалізований на базі фреймворку Streamlit та бібліотеки Plotly. Забезпечує візуалізацію даних за допомогою стовпчастих діаграм (Bar Charts), пелюсткових діаграм (Radar Charts), діаграм розмаху (Box Plots) та теплових карт (Heatmaps).
- **Пакетне завантаження даних (CSV)**: Підтримка масового завантаження відгуків для автоматизованого формування аналітичних звітів.
- **Система авторизації**: Базовий контроль доступу з реєстрацією та аутентифікацією. Забезпечує ізоляцію даних користувачів.
- **Автоматизоване формування інсайтів**: Алгоритмічне визначення сильних та слабких сторін продукту/сервісу, а також найбільш обговорюваних і суперечливих тем.
- **Експорт звітів**: Можливість вивантаження результатів порівняльного аналізу у форматах CSV/Excel.

## Технологічний стек

- **Мова програмування**: Python 3.11+
- **Frontend та UI**: Streamlit
- **Візуалізація даних**: Plotly, Matplotlib
- **NLP та Machine Learning**: Hugging Face `transformers`, `setfit`, `torch`
- **Обробка даних**: Pandas, NumPy
- **База даних**: SQLite3

## Встановлення та запуск

### 1. Клонування репозиторію та налаштування середовища
Переконайтеся, що у вас встановлений **Python 3.11** або **3.12**.
```bash
git clone <посилання_на_ваш_репозиторій>
cd <назва_папки>

# Створення та активація віртуального середовища
python -m venv venv

# Для Windows:
.\venv\Scripts\Activate.ps1
# Для Linux/Mac:
source venv/bin/activate
```

### 2. Встановлення залежностей
```bash
pip install -r requirements.txt
```

### 3. Донавчання моделі (Fine-Tuning)
Перед першим запуском системи необхідно згенерувати навчальний датасет та натренувати власну локальну NLP-модель.
```bash
cd src
python train_setfit.py
```
*Цей процес займе від 2 до 10 хвилин залежно від потужності процесора. Після завершення у директорії з'явиться папка `setfit_absa_model`.*

### 4. Запуск веб-додатку
```bash
streamlit run app.py
```
*Система автоматично відкриється у вашому браузері за адресою `http://localhost:8501`.*

## 📂 Структура проєкту

- `app.py` — головний файл веб-додатку (інтерфейс, авторизація, графіки).
- `nlp_engine.py` — ядро NLP-аналітики. Відповідає за пошук ключових слів, розбиття тексту на речення та взаємодію з натренованою моделлю.
- `train_setfit.py` — скрипт для генерації синтетичного датасету (`training_dataset.csv`) та Few-Shot тренування моделі SetFit.
- `database.py` — логіка роботи з БД SQLite (користувачі, хешування паролів, збереження результатів аналізу).
- `requirements.txt` — список усіх необхідних Python-бібліотек.

## 📝 Критерії оцінювання (Бізнес-метрики)
Модель вміє розпізнавати та оцінювати наступні 11 аспектів:
1. Якість товару
2. Швидкість доставки
3. Робота служби підтримки
4. Ціна
5. Зручність використання сайту (UI/UX)
6. Пакування
7. Асортимент та наявність
8. Процес повернення та гарантія
9. Програма лояльності та знижки
10. Бажання рекомендувати (NPS)
11. Загальне задоволення від покупки
